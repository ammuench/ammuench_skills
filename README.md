# ammuench skills

some agent skills things that I've finally started setting up in a central place for myself. feel free to use em yourself

## the skills

### review-guide

a concise, focused review-guide that covers basic agent review, and also provides a roadmap for the review engineer to parse through code changes logically

### checkpoint-plan

turns an implementation plan into ordered checkpoints: small groups of related changes that are each reviewable, separately committable, and leave the repo green. then works through them one at a time, stopping for review after each one
